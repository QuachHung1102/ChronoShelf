# Issue tracker

Repo chưa có git remote, nên issue và spec tác vụ nằm ở đây dưới dạng markdown.

- Quy ước đầy đủ: `docs/agents/issue-tracker.md`
- Một feature một thư mục: `.scratch/<feature-slug>/`
- Spec: `.scratch/<feature-slug>/spec.md`
- Ticket: `.scratch/<feature-slug>/issues/NN-<slug>.md`, đánh số từ `01`

Spec dài theo cả một subsystem thì thuộc về `docs/superpowers/specs/`, không phải ở đây.
Ticket ở đây khi thuộc một subsystem đã có spec thì trỏ ngược về file spec đó, đừng chép lại.

Thư mục này **được commit** — nó là bộ nhớ của dự án, không phải file tạm.
